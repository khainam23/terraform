Cách chạy:

Cài đặt các gói cần thiết: `terraform init`
Format lại file: `terraform fmt`
Kiểm tra cú pháp: `terraform validate`
Thực hiện lên plan và kiểm tra lại thông tin: `terraform plan`
Triển khai: `terraform apply -auto-approve` thêm -auto-approve để nó triển khai khỏi phải hỏi
Xóa các tài nguyên đã tạo: `terraform destroy -auto-approve` thêm -auto-approve để nó xóa khỏi phải hỏi
